# Brand mark

`mark.svg` is the hoard backlog mark: nine dark tiles, one lit gold and raised by a pixel, as
if found. It stands for the game you should play next, not for buying more.

- Accent token: `hoard-gold`, `#F59E0B`, on the lit tile only.
- Dark tiles: `charcoal-high`, `#2A2A2A`.
- Base: `charcoal`, `#131313`, the app's page background. The SVG itself is transparent.
- Pixel art on a 16 by 16 grid with crisp edges, so it stays sharp at 16 px and at whole-number
  multiples of it.

Checked at 16, 32 and 128 px on `#131313` and on white. It reads at 16 px on both.

This is one of two candidate directions for hoard (the other is an open chest). It is not yet
the app icon.

Drawn by hand as SVG; no image model was used.
